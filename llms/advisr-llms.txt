# Advisr

> Advisr is a New York-based sales operating system for the media and advertising
> industry. Broadcast, publishing, cable and agency sales teams use it to plan
> campaigns, match products to advertiser goals and budgets, generate client-ready
> proposals and presentations, automate approval workflows, and forecast revenue.
> Advisr publishes a public REST API covering the objects inside the platform.

## API at a glance

- Base URL: https://api.advisr.com/v1
- Style: REST over HTTPS, JSON responses
- Auth: company-scoped API key sent as a `token` request header (no Bearer prefix)
- Key issuance: not self-service — contact an Advisr support representative
- Versioning: URI path, `v1`
- Pagination: `limit`, `page`, `sort`, `sortDesc`, `search`; responses carry `page`, `hasMore`, `results`
- Errors: `{"error":{"type":"AdvisrInvalidRequestError","messages":["..."]}}` — not RFC 9457
- Rate limits: a limit exists and returns 429 `AdvisrRateLimitError`; no value, window or headers are published
- Machine-readable contract: NONE. No OpenAPI, GraphQL SDL, AsyncAPI or Postman collection is published.
- Write surface: custom fields and export requests only. There is no way to create a client, campaign or product through the API.

## Endpoints

- `GET /v1/company` — load the company the token belongs to
- `GET /v1/groups`, `GET /v1/group/:id` — company groups (station / region / office units)
- `GET /v1/clients`, `GET /v1/client/:id` — advertisers
- `GET /v1/client/:id/campaigns`, `GET /v1/client/:id/goals`
- `GET /v1/agency/list`, `GET /v1/agency/:id` — media agencies linked to clients
- `GET /v1/campaigns`, `GET /v1/campaign/:id` — campaigns / media plans
- `GET /v1/campaign/:id/product-summary`, `/product-detail`, `/product-recommendation`
- `GET /v1/campaign/:id/geo`, `/audience`
- `GET /v1/campaign/:id/presentation/:format` — pdf or pptx binary (202 while pending)
- `GET /v1/campaign/:id/files`, `GET /v1/campaign/:id/export/:export_type`
- `GET /v1/campaign/:id/support-submissions`, `/fulfillment-submissions`
- `GET /v1/external-crm/linked-campaigns/:externalCrmId/:opportunityId` — CRM opportunity join
- `GET /v1/products`, `GET /v1/products-with-subproducts`, `GET /v1/product/:id`
- `GET /v1/users`, `GET /v1/user/:id`, `GET /v1/user/:id/detail`, `GET /v1/user-by-email`
- `GET /v1/industries`, `GET /v1/industry/:id`, `GET /v1/industry-categories`, `GET /v1/industry-category/:id`, `GET /v1/industry-category/:id/goals`
- `GET /v1/goals`, `GET /v1/file/:id`
- `POST /v1/export/request/client`, `/campaign`, `/campaign-products` — enqueue an async CSV export
- `GET /v1/export/status/:exportId`, `GET /v1/export/download/:exportId`
- `GET /v1/custom-fields/:objectType/:id`
- `POST /v1/custom-fields/:objectType/:objectId/update` — DESTRUCTIVE, replaces supplied keys, no reversal
- `POST /v1/custom-fields/:objectType/:objectId/delete` — DESTRUCTIVE, no reversal
- `POST /v1/custom-fields/:objectType/:objectId/delete-all` — DESTRUCTIVE, no reversal
